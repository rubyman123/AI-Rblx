# fwjelaa Asset Pack

An optional download of ORIGINAL fwjelaa assets made for Roblox (no scraped or third-party packs):
models and kits, stylised materials, skyboxes, R15 animations and VFX textures/meshes.

Install: unzip to `~/fwjelaa-Assets`, or set the `FWJELAA_ASSETS` environment variable to its folder.
Each section has a `CATALOG.csv` (name, tags, size, path) and preview sheets the AI can look at before choosing.
If the pack isn't installed, skills fall back to making assets with the Blender pipeline.
