This third-party icon pack, downloaded on 1 November 2026, is in the Reference Library at `80 Reference Library/ui-icons` (overview: [[80 Reference Library/ui-icons/README|UI icons]]). It holds 3,106 icons in 11 folders. Use it to choose art for the empty `FwjelaaUIIcons` registry in the [[fwjelaa UI Design System]], and as a style reference alongside [[Glossy Icon Style - Owner Reference]].

## Licence
- **Free to ship:** `09 Rank Icons` and `11 Keyboard Keys` (2,550 files) are by RhosGFX under CC0. Credit is optional.
- **Unknown, reference only:** the other nine folders (556 files) have no licence. The pack's README names only its catalogue page, and that GitHub repository has no licence file. Treat these as references until you know who made them and on what terms, like the rest of the Reference Library. Keep them out of the fwjelaa Asset Pack, which holds original assets only.

## How to pick an icon
- **Look first:** open the preview sheets in `ui-icons/sheets`. There is one sheet per folder, and the rank icons, keyboard keys and emojis show a sample.
- **Filter:** `ui-icons/CATALOG.csv` lists every icon's name, folder, size, licence and path.
- **Browse:** open `ui-icons/Browse the icons.html` in a web browser to see every icon with its name.
- **One style per screen:** most icons come in several styles (`Flat_Regular`, `Flat_Outline`, `Glossy`, `Bold`, `Sim`).
- **To use one in a game:** upload your own copy as an image, then put its id in `FwjelaaUIIcons`.

## Common mistakes
- Avoid: shipping icons from the unlicensed folders -> use them as references, or find the creator's licence first
- Avoid: mixing glossy and flat icons on one screen -> pick one style per screen
- Avoid: pasting icon ids found online -> upload your own copy and use its id
