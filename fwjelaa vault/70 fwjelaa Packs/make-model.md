# make-model

Turns a reference picture into a textured Roblox model built in Blender. It compares outlines against the
picture, renders front and back comparisons, and exports only when the model is `ROBLOX READY` and under 20k
triangles.

- Plugin skill: `skills/make-model/` (start with `CLAUDE.md`; `build/BearBuddy.py` is the finished example)
