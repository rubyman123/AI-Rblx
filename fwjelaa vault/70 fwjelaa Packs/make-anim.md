# make-anim

Makes R6 or R15 animations from a reference clip, GIF or screenshots, or from a description. Path A builds in
Blender; path B uses Studio and Moon Animator 2. Every export must print `CHECKS: all clear`, pass contact sheets
from two angles, and match Blender in Studio (`AnimKit.verify` → `MATCHES BLENDER`).

- Plugin skill: `skills/make-anim/` (start with `CLAUDE.md` and `fwjelaa animation method.md`)
- 45 finished animations: [[73 Kits and Models Start Here]]
- Untested so far: the Moon Animator import and `upload.py`
