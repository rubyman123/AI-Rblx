# UI icons

A downloaded icon pack for simulator UI: currency, eggs, gamepasses, boosts, menu buttons, items, ranks, keyboard keys and emojis. How to pick one and which you can ship: [[UI Icon Pack - Third-Party Icons]].

2,151 images in this folder and its subfolders, plus 971 SVG copies of the rank icons and keyboard keys.

`CATALOG.csv` lists every icon with its folder, size, licence and path. `Browse the icons.html` shows them all in a web browser.
